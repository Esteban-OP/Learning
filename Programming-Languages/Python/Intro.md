# Introduction

Python is a widely-used, interpreted, object-oriented, and high-level programming language with dynamic semantics, used for general-purpose programming. Python was created by `Guido van Rossum`.

> [!Note]
> Python has two direct competitors, with comparable properties and predispositions. These are: **Perl** & **Ruby**, both are scripting languages.

Despite Python's growing popularity, there are still some niches where Python is absent, or is rarely seen:
- **low-level programming**: if you want to implement an extremely effective driver or graphical engine, you wouldn't use Python;
- **applications for mobile devices:** although this territory is still waiting to be conquered by Python.
