# Why are they used?

JavaScript libraries and frameworks provide pre-built code that streamlines the development proccess.

## What are Libraries?

Libraries are generally more focused on providing solutions to specific tasks, such as manipulating the DOM, handling events or managing AJAX request.

An example of this is the library jQuery

> [!What is jQuery?]
> Was widely used to simplify DOM manipulation, event handling, animations, effects and more.
