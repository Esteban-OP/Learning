# Compiler

La principal diferencia radica en cómo y cuándo se traduce el código fuente a un lenguaje que la computadora pueda entender

- **Traducción previa:** Traduce todo el código fuente a código máquina o a un archivo ejecutable (como un archivo .exe) antes de que el programa se ejecute.
- **Detección de errores:** Analiza todo el programa y muestra los errores de compilación de manera conjunta antes de dejarte continuar.
- **Velocidad:** El programa resultante se ejecuta mucho más rápido porque la computadora ya tiene las instrucciones listas en su idioma nativo.
- **Ejemplos de lenguajes:** C, C++, Rust, Go.

# Intérprete

- **Traducción sobre la marcha:** Lee y traduce el código instrucción por instrucción (o línea por línea) directamente mientras el programa se está ejecutando, sin crear un archivo ejecutable previo.
- **Detección de errores:** Ejecuta el código hasta que encuentra un error en tiempo de ejecución, momento en el que se detiene.
- **Velocidad:** Es más lento en su rendimiento general porque debe traducir y procesar las instrucciones al mismo tiempo que las ejecuta.
- **Ejemplos de lenguajes:** Python, Ruby, PHP.
