# ¿Que es?

El `DOM` (Document Object Model) es una representacion estructurada de una pagina HTML. Cuando el navegador carga una pagina web, crea una estructura de objetos a partir del HTML.

Cada elemento en el HTML (parrafos, titulos, imagenes, etc.) se convierte en un objeto en el DOM.

![que-es-dom](/Web-Development/assets/img/que-es-dom.png)

## Detalladamente

- `Document`: El archivo HTML.
- `Object`: Cada elemento dentro del archivo HTML.
- `Model`: Eestructura organizada que tienen los objetos entre si. 

Cuando se trabaja con JS se pueden interactuar con estos objetos para cambiar el contenido, estilos, etc.
